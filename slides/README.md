# Slides

Criar `apresentacao.pdf` para 15 minutos. A apresentação deve mostrar a arquitetura completa: Blizzard Classic Game Data API -> snapshots auditáveis -> normalização/curadoria -> Memgraph -> GraphRAG -> Gemini ou fallback.

Sequência sugerida: problema; recorte Classic Era; fonte oficial e limitações de cobertura; esquema do Knowledge Graph; arquitetura; demonstração; fundamentação e fontes; resultados; limitações; conclusão.

Explicar que a API é usada para ingestão e que a demonstração consulta o grafo local, para preservar reprodutibilidade mesmo quando serviços externos estiverem indisponíveis.
