\begin{abstract}
Este artigo apresenta o Azeroth's Oracle, um sistema especialista acadêmico que combina a Blizzard World of Warcraft Classic Game Data API como fonte de ingestão, um grafo de propriedades em Memgraph, recuperação GraphRAG por Cypher e uma LLM para responder perguntas fundamentadas sobre missões e progressão em World of Warcraft Classic Era.
\end{abstract}
