# Limitações

- Cobertura parcial de World of Warcraft, limitada inicialmente a Elwynn Forest em Classic Era.
- A Blizzard Classic API não necessariamente expõe todas as relações de campanha; fatos curados ainda exigem auditoria manual.
- Snapshots representam o momento da sincronização, não uma garantia de disponibilidade ou imutabilidade do serviço externo.
- Resolução de entidade baseada em similaridade textual simples.
- Catálogo limitado de intenções e consultas.
- Disponibilidade e cota de Blizzard API e Gemini são dependências externas; a demonstração usa o grafo carregado e fallback sem Gemini.
- A fundamentação prova quais fatos foram recuperados, mas não garante que a fonte externa permaneça disponível.
